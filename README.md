# happym-site

Páginas públicas e estáticas do HappyM (GitHub Pages):

- `oauth/callback.html`: recebe o retorno do login do Google no celular e o repassa para a TV na rede local. Não guarda nem envia dados para outros servidores.
- `privacy/`: política de privacidade (pt-BR em `index.html`, inglês em `en.html`).
