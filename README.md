# amazinghub-site

Páginas públicas e estáticas da Amazing Hub (GitHub Pages, domínio `amazinghub.app`). Cada app tem a sua pasta.

- `index.html`: página da Amazing Hub com a lista de apps.
- `happyscreen/index.html`: página inicial do HappyScreen (exigida pelo Branding do Google), 5 idiomas.
- `happyscreen/privacy/`: política de privacidade (pt-BR em `index.html`; `en`, `es`, `ja`, `zh-TW`).
- `happyscreen/oauth/callback.html`: recebe o retorno do login do Google no celular e o repassa para a TV na rede
  local. Não guarda nem envia dados para outros servidores.
